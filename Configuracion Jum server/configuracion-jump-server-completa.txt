1.0.4


Ruta del módulo:

C:\Program Files\WindowsPowerShell\Modules\RDWebClientManagement\1.0.4


Debido a restricciones de ejecución, se utilizó temporalmente:

Se desbloquearon los archivos del módulo:

Get-ChildItem "C:\Program Files\WindowsPowerShell\Modules\RDWebClientManagement\1.0.4" -Recurse -File | Unblock-File


Importación del módulo:

Import-Module "C:\Program Files\WindowsPowerShell\Modules\RDWebClientManagement\1.0.4\RDWebClientManagement.psd1" -Force

17. AJUSTE DE IIS PARA EL WEB CLIENT
============================================================

Durante las pruebas, la URL original del archivo index.html
respondía con error 404 aunque el directorio era accesible.

C:\Program Files\RemoteDesktopWeb\Internal\Clients\obc3hirt.yos\content

Posteriormente se respaldó el index original y se reemplazó
por una copia funcional.

Después de este ajuste la URL:

https://WIN-LEU177NL1UK.INFRA2.LOCAL/RDWeb/webclient/index.html

mostró correctamente la pantalla de inicio de sesión HTML5.

============================================================

administrativo y publicación de aplicaciones.

PuTTY y escritorio remoto mediante RemoteApp.

controles de acceso.

El RD Web Client HTML5 fue instalado y publicado correctamente,
aunque el acceso completo quedó limitado por la falta del
listener WebSocket local en TCP 3392.
