============================================================
1. CONFIGURACIÓN DE RED
============================================================

Archivo de Netplan:

/etc/netplan/50-cloud-init.yaml

Configuración:

network:
  version: 2
  ethernets:
    ens3:
      dhcp4: false
      addresses:
        - 10.21.40.130/28
      routes:
        - to: default
          via: 10.21.40.129
      nameservers:
        addresses:
          - 8.8.8.8
          - 1.1.1.1

Aplicar la configuración:

sudo netplan apply

Verificar dirección IP:

ip addr show ens3

Verificar ruta por defecto:

ip route

Resultado esperado:

default via 10.21.40.129 dev ens3

Verificar conectividad con el gateway:

ping 10.21.40.129

Verificar conectividad de red:

ping 8.8.8.8

5. CREAR CERTIFICADO HTTPS AUTOFIRMADO
============================================================

Crear directorio para certificados:

sudo mkdir -p /etc/nginx/ssl

Crear certificado:

sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout /etc/nginx/ssl/webserver.key -out /etc/nginx/ssl/webserver.crt -subj "/C=DO/ST=Santo Domingo/L=Santo Domingo/O=Infraestructura2/OU=WebServer/CN=10.21.40.130"

Permisos:

sudo chmod 600 /etc/nginx/ssl/webserver.key
sudo chmod 644 /etc/nginx/ssl/webserver.crt


============================================================
6. CONFIGURAR NGINX PARA HTTPS
============================================================

Archivo de configuración:

/etc/nginx/sites-available/webserver

Contenido:

server {
    listen 443 ssl;
    listen [::]:443 ssl;

    server_name 10.21.40.130;

    root /var/www/html;
    index index.html;

    ssl_certificate /etc/nginx/ssl/webserver.crt;
    ssl_certificate_key /etc/nginx/ssl/webserver.key;

    ssl_protocols TLSv1.2 TLSv1.3;

    location / {
        try_files $uri $uri/ =404;
    }
}

Eliminar configuración por defecto:

sudo rm -f /etc/nginx/sites-enabled/default

Habilitar nueva configuración:

sudo ln -s /etc/nginx/sites-available/webserver /etc/nginx/sites-enabled/webserver

Verificar configuración:

sudo nginx -t

Reiniciar Nginx:

sudo systemctl restart nginx


============================================================
7. CONFIGURAR SSH
============================================================

Habilitar servicio SSH:

sudo systemctl enable ssh

Reiniciar SSH:

sudo systemctl restart ssh

Verificar estado:

sudo systemctl status ssh


============================================================
8. CONFIGURAR XRDP
============================================================

Habilitar XRDP:

sudo systemctl enable xrdp

Agregar XRDP al grupo ssl-cert:

sudo adduser xrdp ssl-cert

Configurar XFCE para el usuario:

echo "startxfce4" > ~/.xsession

Reiniciar XRDP:

sudo systemctl restart xrdp

Verificar estado:

sudo systemctl status xrdp
